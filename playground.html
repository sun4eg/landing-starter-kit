Buttons

Review the complete Button API across visual variants, sizes, semantics, composition, and resilient content.

Variants

Use the four supported visual treatments to express action hierarchy.

Sizes

.button uses the default medium size; .button--md is its explicit equivalent. Small is intended for compact interfaces. Prefer the default medium size for primary interactive actions.

Width

Buttons use intrinsic width by default, while the full-width modifier fills its immediate container.

Intrinsic width

Full width in a constrained container

Element types

Use a button for actions and a link when navigating to a destination.

Long-content resilience

This constrained example verifies wrapping, comfortable block padding, and containment without horizontal overflow.

Usage guidance

  • Use clear, verb-led labels.
  • Reserve primary styling for the main action.
  • Use links for navigation and buttons for actions.
  • Do not communicate state through color alone.
  • Keep accessible names meaningful.
  • Avoid disabled controls when explanatory feedback would be more useful.
